# Employee Payroll System

## About the Project
The Employee Payroll System is a beginner-friendly Java application that manages employee details and calculates net salaries.

## Features
- Add employee details
- Validate employee ID and salary
- Prevent duplicate employee IDs
- Calculate net salary
- Save employee records to a text file
- Load previously saved employee records
- View employee information

## Technologies Used
- Java
- Java Swing
- ArrayList
- File Handling

## Salary Calculation
- Allowance: 10% of basic salary
- Deduction: 5% of basic salary
- Net Salary = Basic Salary + Allowance - Deduction

## How to Run
1. Install the Java Development Kit (JDK).
2. Download `EmployeePayrollSystem.java`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   `javac EmployeePayrollSystem.java`

5. Run the program:

   `java EmployeePayrollSystem`
